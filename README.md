# Сайт школы №93

Сайт и админка. Python, FastAPI, база SQLite.

## Запустить на своём компьютере (Windows)

1. Установите Python 3.11 или новее с python.org. При установке отметьте галочку «Add python.exe to PATH».
2. Распакуйте архив в любую папку.
3. Откройте PowerShell в этой папке и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

Первый запуск займёт пару минут: скачаются библиотеки и база заполнится данными со старого сайта. Потом браузер сам откроет сайт.

- Сайт: http://127.0.0.1:8000
- Админка: http://127.0.0.1:8000/admin, логин `admin`, пароль `school93-admin`

## Как устроено

| Папка или файл | Что внутри |
|---|---|
| `app/content.py` | Все 46 страниц: заголовки, тексты, блоки. Здесь же таблица редиректов со старых адресов |
| `app/templates/` | Вёрстка страниц (`base.html`, `blocks.html`, `sveden.html`) и админки (`admin/`) |
| `app/static/` | Стили, скрипты, фоны, 3D-объекты, загруженные фото |
| `app/admin.py` | Админка: разделы с данными, журнал, пользователи |
| `app/blocks_store.py` | Конструктор: страницы как набор блоков в базе; блоки людей, документов и кружков хранят ссылки на записи базы |
| `app/pages_admin.py` | Раздел «Страницы»: правка блоков на странице, добавление (+), перестановка, удаление, окно поиска по базе |
| `app/import_news.py` | Загрузка новостей со старого сайта из `news_export.zip`: заголовки, фото, галерея, даты по тексту |
| `app/seed.py` | Первичное наполнение: контакты, приём, 69 человек, около 540 документов со старого сайта, настоящие названия документов восстанавливаются из текста страниц |
| `data/site.db` | База. Появляется при первом запуске |
| `food/` | Файлы меню для мониторинга питания, открываются по адресу /food/ |
| `deploy/` | Установка на сервер: setup.sh, Caddyfile, служба systemd, ночные копии |

## Вход в админку

Вход в два шага: пароль, затем шесть цифр из приложения-ключа на телефоне («Яндекс Ключ», Google Authenticator, Microsoft Authenticator — любое). Номер телефона и почта не нужны, сайт их не хранит. При первом входе каждый подключает приложение по QR-коду и получает 8 резервных кодов на случай потери телефона.

Потерян телефон: войти по резервному коду, администратор в разделе «Пользователи» нажимает «Сбросить ключ». Потеряны и телефон, и коды у последнего администратора: на сервере `python -m app.reset2fa ЛОГИН`.

## Новости со старого сайта

Положите `news_export.zip` (результат `parse_news.py`) в папку проекта или в `data/`. При создании новой базы новости загрузятся сами. Загрузить в уже работающую базу: `python -m app.import_news news_export.zip` (повторная загрузка обновляет, а не дублирует).

## Перенос на сервер

Нужен VPS в России с Ubuntu 24.04 и домен, направленный на его IP. Установка одной командой из папки проекта на сервере:

```bash
sudo bash deploy/setup.sh
```

Скрипт ставит Python и Caddy, запускает сайт как службу, выпускает HTTPS-сертификат и включает ночные резервные копии.
Во время установки скрипт попросит придумать пароль администратора: пароль `school93-admin` годится только для своего компьютера.

## Обновление на сервере

Скопируйте новую версию в отдельную папку на сервере и выполните из неё:

```bash
sudo bash deploy/update.sh
```

Скрипт сначала снимает резервную копию, потом обновляет только код. База, меню в /food и загруженные фото не трогаются. Никогда не копируйте папку проекта поверх /opt/school93 вручную: так затирается рабочая база.
