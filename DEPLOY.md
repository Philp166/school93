# Публикация сайта школы №93 в интернет (бесплатно)

Папка готова к деплою: добавлены `Dockerfile`, `.dockerignore`, `.gitignore`, `render.yaml`.
Всё содержимое (база `data/site.db`, фото, стили) уже внутри — ничего донастраивать не нужно.

## Вариант 1. Render.com — рекомендую (бесплатно, без карты)

Постоянная ссылка вида `https://school93.onrender.com`. Карта не нужна.
Минус бесплатного тарифа: если на сайт никто не заходит ~15 минут, он «засыпает»,
и первый посетитель подождёт 30–60 секунд, пока он проснётся. Для показа заказчику — нормально.

### Шаг 1. Выложить код на GitHub (5 минут)

1. Зарегистрируйтесь на https://github.com (или войдите).
2. Создайте новый репозиторий: кнопка **New** → имя `school93` → Public → **Create**.
3. В этой папке выполните (замените `ВАШ_ЛОГИН`):

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/school93.git
git branch -M main
git push -u origin main
```

### Шаг 2. Деплой на Render (5 минут)

1. Зайдите на https://render.com → **Sign up** → проще всего через кнопку **GitHub**.
2. **New → Web Service** → выберите репозиторий `school93`.
3. Render сам увидит `Dockerfile` и `render.yaml`. Тариф выберите **Free**.
4. Нажмите **Deploy**. Сборка идёт 3–7 минут.
5. Готово — сверху появится ссылка вида `https://school93.onrender.com`. Её и шлите заказчику.

Админка: `https://school93.onrender.com/admin`, логин `admin`, пароль `school93-admin`
(пароль смените после первого входа).

### Обновления

Поменяли что-то в коде локально → `git add -A && git commit -m "правки" && git push` —
Render сам пересоберёт и обновит сайт.

### Важно знать

- **Правки через админку живут до ближайшего пересборки/перезапуска.** Бесплатный тариф
  не хранит диск: загруженные через админку файлы и изменения базы пропадут при деплое
  или перезапуске. Для демо это ок; для постоянной работы — либо платный диск на Render,
  либо VPS (инструкция лежит в исходной папке `deploy/`).
- Чтобы сайт не «засыпал», можно раз в 10 минут дёргать его бесплатным пингом
  (например, cron-job.org → новый cronjob на адрес сайта).

## Вариант 2. Hugging Face Spaces — запасной (тоже бесплатно, без карты)

1. Регистрация на https://huggingface.co → Settings → Access Tokens → создать токен (write).
2. Создать Space: **New Space** → SDK выбрать **Docker** → Blank.
3. Запушить эту папку в git-репозиторий Space — сайт поднимется на
   `https://ВАШ_ЛОГИН-school93.hf.space`.
